# 📊 Madhav Sales Dashboard

An interactive sales analytics dashboard built using **Power BI** to visualize and analyze key business metrics from Madhav Sales.

## 📁 Project Overview

This dashboard provides a comprehensive view of sales performance, product trends, regional analysis, and profitability to support data-driven decision-making.

## 🛠 Tools & Technologies
- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel (CSV Files)

## 📂 Datasets Used
- `Orders.csv`: Contains order-level data such as order date, customer, and region.
- `Details.csv`: Includes detailed line items like product, quantity, and sales amount.

## 📈 Key Features
- Visualized key KPIs: Total Sales, Profit, Orders, and YOY Growth
- Region-wise sales analysis with dynamic filtering
- Product category and sub-category performance
- Monthly sales trend visualization
- Target vs Actual comparison charts
- Interactive slicers and filters for user-driven analysis

## 📌 Impact
- Automated reporting reduced manual effort by **70%**
- Uncovered a **20% sales increase in the North region**
- Enabled quick identification of high-performing products and underperforming areas
